# SQL

**SQL** steht für *Structured Query Language*, zu Deutsch *strukturierte Abfragesprache*. Es handelt sich dabei um eine spezialisierte Programmiersprache, die entwickelt wurde, um Daten aus [[Databases (DE)|Datenbanken]] abzufragen, zu analysieren und zu manipulieren. Heutzutage zählt SQL zu den am weitesten verbreiteten Werkzeugen im Bereich der Datenverarbeitung und Datenanalyse. Wer mit großen Datenmengen arbeitet, kommt an SQL praktisch nicht vorbei.

SQL basiert ursprünglich auf zwei mathematischen Konzepten: der *relationalen Algebra* und dem *relationalen Tupelkalkül*. Diese theoretischen Fundamente ermöglichen es, Daten in strukturierter Form zu organisieren und präzise Abfragen zu formulieren.

SQL wird grundsätzlich als *deklarative Sprache* klassifiziert und gehört zur sogenannten vierten Generation der Programmiersprachen (*4GL*). Das bedeutet, dass man in SQL beschreibt, *welche* Daten man haben möchte, ohne im Detail festlegen zu müssen, *wie* das System diese Daten beschaffen soll. Dennoch enthält SQL auch *prozedurale Elemente*, die es erlauben, Abläufe und Logik in Form von Schleifen oder Bedingungen zu definieren.

## SQL-Dialekte

Obwohl alle SQL-Varianten eine gemeinsame Grundstruktur teilen, unterscheiden sich einige spezifische Befehle und Schreibweisen je nach verwendetem System leicht voneinander. Diese Varianten werden als *Dialekte* bezeichnet. Zu den bekanntesten SQL-Dialekten gehören MySQL, SQLite, SQL Server und Oracle SQL.

Für Einsteiger empfiehlt sich **PostgreSQL** als guter Ausgangspunkt. Dieser Dialekt orientiert sich eng an der standardisierten SQL-Syntax und lässt sich problemlos auf andere Dialekte übertragen. Wer PostgreSQL beherrscht, kann sich daher schnell in andere Systeme einarbeiten.

## Die Teilsprachen von SQL

SQL besteht aus verschiedenen Anweisungstypen, die in sogenannte *Teilsprachen* (auch Sublanguages genannt) unterteilt werden:

- **DQL (Data Query Language):** Dient dem Abfragen und Abrufen von Daten aus der Datenbank.
- **DDL (Data Definition Language):** Wird verwendet, um die Struktur der Datenbank zu definieren, etwa das Erstellen oder Ändern von Tabellen.
- **DCL (Data Control Language):** Regelt die Zugriffsrechte und Berechtigungen innerhalb der Datenbank.
- **DML (Data Manipulation Language):** Ermöglicht das Einfügen, Aktualisieren und Löschen von Datensätzen.
