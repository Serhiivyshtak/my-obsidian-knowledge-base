# Obsidian Knowledge Base

A personal [Obsidian](https://obsidian.md/) vault used to collect, organize, and connect notes on topics I am learning. Notes are written in Markdown and linked together with Obsidian's wiki-style `[[links]]`, so related ideas can be explored as a network rather than a flat list of documents.

This repository is a living reference: it will grow over time as new subjects are studied and existing notes are refined.

## How to use this vault

1. **Open in Obsidian** — Clone or download this folder, then open it as a vault in Obsidian (File → Open folder as vault).
2. **Browse notes** — Each `.md` file is a standalone note. Follow links between notes to move from overview topics to more specific ones.
3. **Explore the graph** — Use Obsidian's Graph view to see how notes connect. A snapshot of the current graph is included below.

## Structure

Notes are grouped by broad subject areas. Some notes act as entry points or indexes; others go deeper into a single concept. Cross-links tie related ideas together across topics.

There is no fixed curriculum — new notes and links are added as learning continues.

## Requirements

- [Obsidian](https://obsidian.md/) (desktop or mobile)
- No plugins are required to read the notes; the `.obsidian` folder holds local editor settings only.
